# 本地诊断：回归补齐实施记录

依据：已确认的 `2026-09-28-agent-workflow-review.md`。

## 交付

既有 `diagnose` Python/CLI 入口增加可选 `completion`，未配置时保持原始诊断。配置模型后输出：

1. 模型加载、哈希及验证状态检查；固定宽度/温度、NMOS 类型及几何范围检查。
2. Spec 启用指标的原始有效值与预测值对比，可选绝对偏差容差；未配置则明确 NOT_ASSESSED。
3. 仅补齐缺失指标；无效值、原始有效值和实测超限证据保持不变。
4. 单份 HTML 的综合判定和带 predicted 的核心指标表；原始判定保留在追溯区。
5. JSON 1.1 及新增综合明细、模型检查 CSV。原始统计不包含本次预测补齐值。

模型不可用不阻断已有数据分析；没有通过独立验证的模型只能提供参考预测，不能被自动采用为补齐依据。超出显式偏差容差时暂停该器件补齐。

诊断指标表允许同一器件跨来源保留记录，但同一器件/条件/来源重复仍拒绝。旧的严格训练/导入行为不变。

## 主要代码边界

- `analysis/completion.py`：适用性、对比与补齐策略，不修改训练算法。
- `api.py` / `workflows/diagnose.py`：请求验证、调用、哈希追溯与输出。
- `analysis/diagnosis_report.py`：综合判定与核心指标展示。
- `tests/test_completion.py`：使用合成数据验证功能与故障边界，不代表真实器件精度。

## 已完成的本地检查

- 对既有输入的副本隐藏 SS：原始诊断为 13 个 INCOMPLETE、2 个 FAIL；补齐后为 13 个 PREDICTED_PASS、2 个 FAIL。15 个 SS 补齐项均标记为预测。
- 对完整输入运行模型对比，不采用任何补齐值。
- 单独检查 3 个独立验证器件的 SS，最大绝对偏差约 2.87 mV/dec。这是现有 COMSOL 参考上的有限验证，不是工业制造波动或通用误差上限。
- CLI 与 Python 使用同一实现，补齐请求已实际运行。
- 全套 147 项测试通过；随后新增 3 项边界用例，补齐专项全部 15 项通过（12 项已包含在此前全套中）。

私有请求、验证细节及报告保存于本地忽略目录；公共文档不包含私有原始数据。

## 本轮限制

- 不提供校准的预测区间；所有含补齐的通过结论均为暂定预测结论。
- 几何范围内不等于参数组合附近有充分训练支持；不自动认证新工艺或材料。
- 客户负责选择与测量合约、器件结构相匹配的已发布模型；本轮不自动搜索模型库。
- 不自动跨来源查库补充 COMSOL，不迁移完整数据库，不自动校准或重训。
- 不推断根因，不修改 Spec；后续 agent 可以调用当前结构化接口，但本轮未建立独立对话运行器。

请求配置、返回字段与语义见 `docs/diagnosis.md`。
